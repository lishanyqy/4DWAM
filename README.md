# 4D-WAM project page

Static project page for **4D-WAM: Infusing Spatiotemporal Awareness into World Action Models through Trajectory Fields** (arXiv:2608.08023).

- `index.html` — the page
- `static/css/style.css`, `static/js/main.js` — styles and the interactive robot-platform hotspots
- `static/images/` — figures (SVG/PNG) and video posters
- `static/videos/` — web-compressed (720p H.264) real-world rollouts and the prediction comparison
- `static/paper.pdf` — the paper

To edit a hotspot, change the `left`/`top` percentages on the matching `.hotspot` element in `index.html`; the tooltip text lives right next to it.
